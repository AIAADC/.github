## 🎒 从这里开始

初次使用，先进入所在年级的总仓；查找某一门课，直接使用下面的课程地图。年级总仓提供导航，课程仓集中保存资料与使用说明。

| 年级入口 | 可以找到什么 |
| --- | --- |
| **[大一课程资源总仓](https://github.com/AIAADC/Resources-for-freshman-in-AIA)** | C 语言、微积分、线性代数、大学物理、概率论，以及思政、英语等资料 |
| **[大二课程资源总仓](https://github.com/AIAADC/Resources-for-sophomore-in-AIA)** | 复变、数电、模电、离散、信号、人工智能、数据结构、运筹学等课程资源 |
| **[大三课程资源总仓](https://github.com/AIAADC/Resources-for-junior-in-AIA)** | 当前整理大三上：计算机网络、传感技术、电机拖动基础、微机原理、自动控制原理（二）、模式识别与机器学习（自动化专业） |

> **学习时**按章节查课件，补齐概念与推导；**复习时**先列知识框架，再用例题检查薄弱处。具体资料范围与复习建议见各课程 README。
